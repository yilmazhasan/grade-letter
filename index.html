How to Use

  1. Set grade boundaries: Drag the slider handles or add/remove ranges using the controls above. Each range starts at the entered percentage and extends to the next handle.
  2. Paste grades: Enter or paste all student scores into the Input Grades box (one per line or space-separated).
  3. Review results: The Results column shows each student's assigned letter. The Sorted column orders by score descending.
  4. Manual override: In the Sorted column, change any letter — all grades below/above that grade in the same category will update proportionally.
  5. Equalize letters: Set a point tolerance in Equalize within ± and click Equalize Letters to make students within that range receive the same letter.
  6. Re-calculate: Click Re-calculate after adjusting slider handles to refresh all results.
